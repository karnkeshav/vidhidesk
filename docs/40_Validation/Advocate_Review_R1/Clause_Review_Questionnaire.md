# Clause Review Questionnaire

**How to use this form:** for each matter, open its `Review_Package_<ID>.md` side by side with this section. Work through the 14 clauses in order (the same order they appear in the review package and in the composed draft). Fill every column — an empty cell is itself informative, but a clear "N/A" is better than leaving it blank if a question genuinely does not apply. After the 14-clause table, answer the Overall Pleading Assessment questions for that matter.

**Column key:**
- **Legally correct?** — Does this clause state the law/facts accurately, as far as you can tell? (Yes / Partially / No)
- **Missing?** — Is there a legally material point, fact, or citation this clause should have but doesn't? (Yes — describe / No)
- **Unnecessary?** — Does this clause include anything that shouldn't be there (irrelevant, wrong register, redundant)? (Yes — describe / No)
- **Rewrite?** — Would you rewrite this clause yourself rather than lightly edit it? (Yes / Lightly edit / No, file as-is)
- **Would file?** — If this were the only version available, would you file it as-is, today? (Yes / No)
- **Confidence (1–5)** — Your confidence in this clause's legal correctness and fitness to file. 1 = would not rely on this at all, 5 = fully fit to file with no changes.

For any "Partially"/"No"/"Yes — describe" answer, add a row to `Feedback_Capture_Template.md` referencing the matter, clause, and version shown in the review package — do not rely on this table alone to carry detailed comments, since it does not have a Severity or Suggested Improvement column.

## Cross-Matter Reflection (fill in once, after all 6 matters)

These questions ask about patterns across the whole review, not any single matter — answer them last.

1. **Which single clause type (Cause Title, Facts, Legal Grounds, etc.) was most consistently weak across the 6 matters?** Why?

2. **Which single clause type was most consistently strong?** Would you trust that clause type to go straight to a "lightly edit" workflow rather than a full rewrite, across future matters of a similar type?

3. **Did any clause ever state something as fact/law that you know to be incorrect, not just incomplete?** (This is the single most important question in this questionnaire — a confidently wrong statement is a different, more serious problem than a missing one. List every instance, however minor.)

4. **Did the system ever cite a statute or case correctly that you would NOT have thought to check yourself?** (A positive finding is as useful to record as a negative one.)

5. **Overall, across all 6 matters, would you want to keep evaluating this system with more matters, or does today's review already tell you enough to form a view?**
